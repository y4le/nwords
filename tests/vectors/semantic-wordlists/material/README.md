# Authored Material Wordlist

This fixture pins the authored `material` list used by `nwords`.

Source posture:

- Authored in-repo; no upstream list is transformed into the shipped words.
- Seed references were used only as review aids for common material labels.
- Seed references:
  - Princeton WordNet license and lexical database:
    <https://wordnet.princeton.edu/license-and-commercial-use>
  - Wikidata licensing for structured data:
    <https://www.wikidata.org/wiki/Wikidata:Licensing>

Policy:

- Keep lowercase ASCII single-token words.
- Freeze words in alphabetical order.
- Prefer common materials that work as pre-noun modifiers.
- Include a small number of common wood and fabric names because they read
  naturally in phrase shapes.
- Exclude brands, proprietary materials, gemstones primarily used as names,
  animal-body terms, hazardous substances, and highly technical alloys.

Count:

- `material`: 64 authored words.

Regenerating, editing, or reordering this list is a new wordlist version, not
an in-place compatibility edit.
