BIP-39 · ENGLISH

Entropy to mnemonic

checksum

A standards-compliant wallet mnemonic from entropy. Edit either side to check the checksum and recover the bytes.

⇄

Open this demo to load the BIP-39 codec.

Accepts 16, 20, 24, 28, or 32 bytes (12–24 words). This educational page is not a wallet. Do not use its sample phrases to protect funds.

JAVASCRIPT
import { loadBip39 } from '@y4le/nwords/bip39/web';

const bip39 = await loadBip39();
const entropy = new Uint8Array(16); // public test vector
const phrase = bip39.encodeEntropy(entropy);
const original = bip39.decodeMnemonic(phrase);
